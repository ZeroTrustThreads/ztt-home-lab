# References and Source Policy

The lab uses primary documentation whenever possible. Product interfaces and supported versions change, so learners should compare the instructions with the current source before starting.

## Core sources

### Apple

- [View About settings on Mac](https://support.apple.com/guide/mac-help/view-about-settings-mchlea7173f3/mac) — identify the Mac chip or processor, memory, storage, and macOS version.
- [Mac computers with Apple silicon](https://support.apple.com/en-us/116943) — recognize Apple silicon models and terminology.

### UTM

- [UTM documentation](https://docs.getutm.app/) — official product documentation and feature overview.
- [Install UTM on macOS](https://docs.getutm.app/installation/macos/) — official installation choices and update guidance.
- [Linux guest support](https://docs.getutm.app/guest-support/linux/) — Linux guest tools and sharing features.
- [UTM network settings](https://docs.getutm.app/settings-qemu/devices/network/) — virtual network modes and device settings.

### Windows and VMware Workstation

- [Broadcom: Downloading free software](https://knowledge.broadcom.com/external/article/397417/downloading-free-software-from-the-broad.html) — current portal workflow for free software.
- [Broadcom: Download VMware Workstation Pro](https://knowledge.broadcom.com/external/article/344595/downloading-vmware-workstation-pro.html) — current Workstation download path.
- [Broadcom: Desktop hypervisor downloads](https://knowledge.broadcom.com/external/article/368734/download-desktop-hypervisor-workstation.html) — account, verification, and product-download details.

### Linux and GNOME Boxes

- [GNOME Boxes help](https://help.gnome.org/gnome-boxes/index.html) — official task and concept documentation.
- [Create a box](https://help.gnome.org/gnome-boxes/create.html) — ISO selection and VM creation.
- [GNOME Boxes system requirements](https://help.gnome.org/gnome-boxes/system-requirements.html) — hardware virtualization and resource guidance.
- [Technology used by Boxes](https://help.gnome.org/gnome-boxes/supported-protocols.html) — QEMU, KVM, libvirt, and SPICE concepts.

### Ubuntu Server

- [Download Ubuntu Server](https://ubuntu.com/download/server) — official installation images.
- [Ubuntu Server installation](https://documentation.ubuntu.com/server/how-to/installation/index.html) — installation guidance and architecture-specific resources.
- [Ubuntu Server reference](https://documentation.ubuntu.com/server/reference/index.html) — system requirements and reference material.
- [OpenSSH server](https://documentation.ubuntu.com/server/how-to/security/openssh-server/) — server installation, configuration, and SSH keys.
- [Ubuntu firewall](https://documentation.ubuntu.com/server/how-to/security/firewalls/index.html) — `ufw` and Linux firewall concepts.
- [APT upgrades and phased updates](https://documentation.ubuntu.com/server/explanation/software/about-apt-upgrade-and-phased-updates/) — why packages may be held back and why proposed changes should be reviewed.
- [Upgrade an Ubuntu release](https://documentation.ubuntu.com/server/how-to/software/upgrade-your-release/) — LTS guidance, preparation, backups, and release upgrades.

### Docker

- [Install Docker Engine on Ubuntu](https://docs.docker.com/engine/install/ubuntu/) — supported Ubuntu releases, installation methods, verification, and firewall warnings.
- [Docker Engine installation overview](https://docs.docker.com/engine/install/) — supported platforms and installation choices.

## How sources are used

Each guide ends with a **Sources and further reading** section. Sources support product-specific procedures and security claims. Explanations and exercises connect those facts to the lab's learning objectives.

## Reporting outdated guidance

When reporting an outdated step, include:

1. The guide and heading.
2. The behavior you observed.
3. The relevant product and version.
4. A link to current official documentation.
5. A suggested correction, if known.

Do not include credentials, private keys, personal addresses, or other sensitive information.
