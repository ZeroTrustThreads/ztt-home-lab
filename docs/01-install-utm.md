# Install UTM

## Goal

Install UTM from an official source and confirm that it opens successfully.

## Steps

1. Visit the official UTM website at <https://mac.getutm.app/>.
2. Choose the installation option appropriate for your Mac.
3. Install and open UTM.
4. If macOS requests permission, read the prompt and approve only what is required for virtualization.
5. Confirm that the UTM main window opens without an error.

UTM may be available directly from its website and through the Mac App Store. Review the differences described by UTM before choosing.

## Checkpoint

You should be able to open UTM and see the option to create a new virtual machine.

Do not create the VM yet. Continue to [Create the Ubuntu Server VM](02-create-ubuntu-server-vm.md).
