# Contributing

Thank you for helping improve the Zero Trust Threads Cybersecurity Home Lab.

Useful contributions include:

- Correcting inaccurate or outdated instructions
- Making a step easier for beginners to understand
- Improving accessibility
- Adding safe troubleshooting guidance
- Reporting broken links
- Testing instructions on supported hardware

Before proposing a change:

1. Explain the learner problem being solved.
2. Keep instructions focused and reproducible.
3. Use official download sources.
4. Never include real credentials, private keys, personal IP addresses, or sensitive screenshots.
5. Clearly label commands and expected results.
6. Test every changed procedure when possible.

By submitting a contribution, you agree that Zero Trust Threads may use and distribute it as part of this project under the repository's license terms.
