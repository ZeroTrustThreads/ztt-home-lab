# Foundation Validation Checklist

Complete each item before moving to later labs.

- [ ] UTM opens successfully.
- [ ] The Ubuntu Server VM starts without the installer ISO.
- [ ] A non-root administrator account can sign in.
- [ ] The VM has a private IP address.
- [ ] Ubuntu package information is current.
- [ ] Available operating-system updates are installed.
- [ ] The SSH service is active.
- [ ] The Mac can connect to the VM through SSH.
- [ ] `whoami` returns the expected Ubuntu username during the SSH session.
- [ ] `hostname` returns the expected VM hostname during the SSH session.
- [ ] The VM configuration is documented below.
- [ ] A clean UTM snapshot has been created after validation.
